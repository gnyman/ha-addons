# My repository

This is a small repository where I will share my home-assistant addons.

Add-ons are pinned to their source repositories using Git submodules.

## havnc 

The normal version of havnc, it's the one I recommend and that I would personally use.

## havnc-dragons

Here be dragons, this is the latest and possibly (likely?) broken version of havnc, this is for masochists and people who run arch


## phev

Mitsubishi Outlander PHEV to MQTT, with Home Assistant discovery, charge-timer
override control, detailed charging state, and reconnect recovery. The source
includes the patched bridge, so Home Assistant builds the app on installation;
no separately published container image is required.

Source: https://github.com/gnyman/home-assistant-addon-phev2mqtt

See [installation and migration from a local copy](docs/phev-installation.md).
